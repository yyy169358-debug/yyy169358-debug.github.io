# WaveCut Web Experience

独立、无后端的浏览器本地音频剪辑体验。此次无法取得原聊天中的网页附件，因此重新实现此轻量版本；没有修改或替代 V10 Windows/macOS 项目。

## 功能

- 导入浏览器支持的音频（WAV、MP3 等；最大 100 MB、最长 10 分钟）
- 合成演示音频、波形显示、起止点选段、播放位置、暂停、停止、循环
- 峰值归一化至约 −1 dB、两端各最多 250 ms 淡入淡出
- 基于 10 ms 窗口 RMS 音量的首尾静音检测；保留约 30 ms 余量，支持调整阈值
- 导出所选音频为 16-bit PCM WAV，保留解码后的采样率与声道

## 能力与隐私

所有音频处理在浏览器内执行，不上传音频，无分析追踪、外部字体、API 密钥或外部运行依赖。GitHub Pages 仍负责提供网页资源。页面刷新后音频和选段不保留。

静音检测是阈值启发式算法，不是 AI 模型；可能遗漏轻声或尾音，需要试听确认。没有语音识别、人声分离、生成式降噪或桌面版模型推理。峰值归一化不是广播响度标准化。浏览器可能将输入重采样到当前 AudioContext 的采样率。格式兼容性取决于浏览器。
