# WaveCut 音乐时长重组网页预览

这个独立静态网页提供“上传整首音乐 → 输入目标秒数 → 自动重组 → 试听与导出”的主流程。它参考 [WaveMix](https://wavemix.cn/) 的公开功能重新实现，并非该站源码或 1:1 等效版本。没有修改 Windows/macOS V10 工程。

## 已实现

- 浏览器分析整首音乐，估计拍速、拍点、调性和段落候选。
- 输入目标秒数，生成多套缩短或延长剪法；保留原曲开头和结尾，优先在完整小节与乐段边界跳接或重复。默认保持原速，允许最多约 0.85 秒的时长偏差；可选严格时长校正。
- 预听成品、接缝和结尾；查看片段来源、调整切点及段落标签。
- 对同一首音乐的候选剪法做节奏、音色、接缝响度初筛；不通过的剪法不会提供为成品。自动短淡化只用于去除杂音，轻微音量校正不会代替选择合适切点。渲染后还检查削波、接缝瞬态杂音，并在鼓点足够清晰时复检接缝两侧的节拍相位。可导入带时间的 SRT/LRC 歌词保护句中切点，也可在浏览器下载 Whisper tiny 模型识别唱词。
- 导出 WAV、带接缝标记的 WAV、SRT、CUE、剪辑决定表和工程文件；可将分析和剪法保存到本机浏览器。
- 可自行配置兼容 Chat Completions 的 AI 服务，让其根据分析摘要比较剪法。该服务不会听到原音频，调用时会发送剪法摘要和歌词。

## 当前限制

节拍、调性、段落和接缝评分主要是浏览器本地数字信号处理与启发式规则，不是参考站所用的 All-In-One、Beat This、Demucs、Silero 或 SenseVoice 模型。Whisper 唱词识别依赖首次从 Hugging Face 下载模型，准确性及时间戳未经等效验证。人声、气口、歌词及自然收尾仍需试听核对。账号及云端同步尚未实现。浏览器工程不保存原音频，重新打开时需再次导入同一首曲目。

参考站的[公开指南](https://wavemix.cn/guide-shorten.html)说明了段落边界、无唱句、整小节与允许少量时长偏差等原则；其[公开工作线程](https://wavemix.cn/assets/retarget-web/web/retarget-worker.js?b=1790156350)把候选方案求解交给服务端，完整评分权重无法从网页确认。WaveCut 的节拍复检是依据公开可见的渲染后核验流程独立实现，并非参考站内部算法的复制。

上传音频最长 10 分钟、最大 100 MB；格式支持取决于浏览器解码器。音频在本机处理，只有用户主动调用自带密钥的 AI 服务时才会发送文字摘要。GitHub Pages 只托管静态网页。
